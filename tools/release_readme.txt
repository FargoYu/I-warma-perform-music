沃要吹灭火器 / I warma perform music — Demo v0.2
Windows x86_64

解压后双击 Warma-Demo-v0.2.exe 运行，无需安装 Godot。
请完整解压压缩包后运行。存档仅保留在本次游戏中，退出游戏后重置。

按任意键开始。
A / D：左右移动
J：跳跃，长按跳得更高；保持按住可连续跳跃
K：获得灭火器后，每次点按发射一个音符
W：站在门口时进入下一房间
R：重开当前房间，保留已获得的灭火器和时间倍率
P：暂停 / 继续
← / →：调慢 / 调快时间（x0.1、x0.2、x0.5、x1）
F1：显示 / 隐藏碰撞边界
N：测试快捷键，立即获得灭火器
M：测试快捷键，直接使用当前房间第一扇门

共 16 个主线房间。结束画面按任意键退出。
保留落地、发射、受击、拾取、换房、重试与界面提示音效。
行走、起跳与告示牌交互保持安静，没有背景音乐。
