# 沃要吹灭火器 · 音效包

轻松、愉快、略带玩具感的原创程序合成音频。没有使用外部音乐、录音采样或人声。

## 音效

所有音效为 44.1 kHz、16-bit、单声道 WAV，不循环。
游戏使用全部 15 个音效。行走、起跳和告示牌交互保持安静，没有背景音乐；未使用的音频素材已删除。

| 文件 | 用途 | 时长 |
| --- | --- | --- |
| land | 低沉柔软的落地声 | 0.12 秒 |
| shoot_01 / shoot_02 / shoot_03 | C / E / G 三种音符发射音，依次轮换 | 各 0.22 秒 |
| giraffe_hit | 木琴跳音，长颈鹿受击 | 0.305 秒 |
| wall_hit | 音符碰墙时的小颗粒声 | 0.12 秒 |
| pickup | 拾取灭火器的上行铃音 | 0.805 秒 |
| door | 进入房间的拨弦琶音 | 0.60 秒 |
| restart | 温和的重试提示 | 0.60 秒 |
| confirm | 开始游戏的确认音 | 0.375 秒 |
| pause / resume | 下行 / 上行两音提示 | 各 0.28 秒 |
| time_down / time_up | 调慢 / 调快时间的三音提示 | 各 0.35 秒 |
| complete | 完成游戏的小庆祝旋律 | 1.73 秒 |

## Godot 接入与调节

已经自动加载 `scripts/audio_manager.gd`。`default_bus_layout.tres` 提供 SFX 总线，默认 -3 dB，Master 限幅器保留峰值余量。音效保持正常音高与速度，不跟随解谜时间倍率变化。

- 暂停和继续时分别播放简短提示音。
- 落地需要从空中落下达到一定速度，初始出生不触发。
- 同类碰撞有 65 毫秒合并间隔，音效池最多 16 声并行；快速发射仍逐次反馈。
- 可在 Godot 的 Audio 面板调整 SFX 总线，或调用 `AudioManager.set_sfx_volume_db(-3.0)`。这些设置仅作用于当前运行。

## 重新生成

运行 `python tools/generate_audio.py`（需要 NumPy）可重建音效。
固定随机种子用于打击噪声，所有音效的音色和短旋律都在脚本中可编辑。

`artifacts/audio/` 保存数值检查报告；此目录由项目现有 Git 忽略规则排除。游戏资源位于本目录下的 SFX。
