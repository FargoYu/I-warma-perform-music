# IWPM：沃要吹灭火器

欢迎来到 IWPM（I warma perform music）！这是一款像素风平台跳跃游戏。你将操纵沃玛穿过一间间房间，跳跃、探索，并用音乐灭火器和长颈鹿互动，找到通往下一关的门。

## 怎么玩

一路前进，观察房间里的地形、机关和告示牌。途中可以找到灭火器；拿到之后，就能发射音符推动长颈鹿。试着利用它们的位置和移动，为沃玛开出一条路。遇到困难时，可以从当前房间重新开始。

## 操作

- `A` / `D`：向左 / 向右移动
- `J`：跳跃；轻按跳得较低，按住跳得更高，也可以按住连续跳
- `W`：靠近门时进入下一房间
- `K`：拿到灭火器后发射音符
- `←` / `→`：调整游戏时间流速，方便进行精细操作
- `R`：重新开始当前房间；掉出屏幕也会回到房间起点

## 冒险提示

- 长颈鹿会与沃玛、方块和彼此发生碰撞，可以观察它们的堆叠与位置来规划路线。
- 音符会推动长颈鹿；想好发射方向，让它们帮你处理眼前的障碍。
- 房间里的告示牌会提供当前关卡的提示。
- 死亡后会恢复进入房间时的状态；已经拿到的灭火器会随你继续前进。

祝你玩得开心，演奏出一条通往终点的路！
