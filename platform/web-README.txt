沃要吹灭火器 v1.3 — 单文件网页版（电脑 + 安卓浏览器）

本地游玩：解压本包后，直接双击 index.html，用新版 Chrome 或 Edge 打开。
不需要 CMD、Python、Godot、本地服务器或联网。游戏及音频资源已包含在 HTML 中。
首次加载需要解压资源，请等待准备画面；首次点击/触摸/按键后浏览器才允许声音播放。

网站游玩：同一个 index.html 可直接部署到 GitHub Pages 或其他 HTTPS 静态托管。
发布时请一并保留本目录的字体和引擎许可证。所有资源均为相对页面内嵌数据，支持仓库子路径。
安卓手机在浏览器打开托管网址，自动显示多点触屏操作区，无需安装 APK。
手机文件管理器对本地HTML的打开方式各有差异，手机建议访问GitHub Pages网址。

电脑：A/D 移动，J 跳，K 演奏，W 进门，R 重来，P/Esc 暂停，左右方向键调速。
手机：多点触屏，可同时移动与跳跃/演奏；横竖屏均适配，建议横屏游玩。
右上角可以全屏；界面自动避开刘海与底部手势区域。
切到后台后暂停，返回后点击“继续”或按P/Esc。通关后返回标题，不关闭网页。
游戏没有跨次游玩的存档。

开发者重新构建：项目根目录 python tools/export_all.py --platform web。
GitHub仓库与Pages发布步骤请看源码包的 GITHUB-PAGES.txt。
