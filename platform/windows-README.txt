沃要吹灭火器 v1.3 — Windows x86_64

双击 Warma.exe 即可运行，不需要安装 Godot。
支持可调整大小的窗口，画面保持比例，完整显示关卡。

A / D：移动；J：跳跃；K：发射音符；W：进门。
R：重来；P / Esc：暂停和继续；方向键左 / 右：调节时间倍率。
开场按任意键或点击开始，通关后按任意键或点击返回标题。
切出窗口后会自动暂停，回来后按 P / Esc 继续。
没有跨次游玩的存档。

触屏电脑会自动显示触屏按钮。也可用命令 Warma.exe -- --touch-controls 试用。
本发布包未进行 Windows 商业代码签名。
