沃要吹灭火器 v1.3 — Android

将 Warma.apk 复制到手机，打开后按系统提示允许该来源安装应用。
安装包包含 ARM64、ARMv7 和 x86_64，适用于 Android 7.0 及以上、支持 OpenGL ES 3.0 的设备。
本包为已签名的 Release APK，可直接安装，不是应用商店 AAB。

横屏游玩，左右旋转均可；底部为独立触控区域，不遮挡关卡。
左 / 右：移动；跳跃：跳跃；演奏：发射；进门：进入下一关。
重来、暂停、减速和加速都可通过触屏操作，支持同时移动和跳跃/发射。
系统返回键暂停/继续；切到后台后暂停，返回应用后点击继续。
通关后轻触返回标题，可重新开始。没有跨次游玩的存档。

签名私钥未包含在分发目录。后续覆盖升级必须保留开发目录中的相同私钥。
